# Unidade 2 - Exploração inicial em Excel

Primeira leitura da base de acidentes da PRF 2025 usando Excel, antes de partir para SQL e Python.

## Arquivo

`modulo_02_excel_prf_thyago_antonio.xlsx`

## O que foi feito

- Importação do CSV bruto (`dados_brutos/acidentes2025.csv`)
- Construção de um dicionário resumido das colunas
- Tabelas dinâmicas por UF, causa do acidente, tipo de acidente e fase do dia
- Gráficos exploratórios sobre volume de acidentes e distribuição de fatalidades
- Registro das primeiras observações e hipóteses

## Como usar

1. Abra `modulo_02_excel_prf_thyago_antonio.xlsx`
2. As tabelas dinâmicas e gráficos já estão calculados sobre a aba `dados`
3. Para recalcular, use Dados > Atualizar Tudo
